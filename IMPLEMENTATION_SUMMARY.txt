   - Builds intelligent item index
   - Resolves wikilinks to API URLs

2. BUILD AUTOMATION (Nushell Script)
   File: scripts/build-rustdoc.nu
   - Discovers Rust projects
   - Generates rustdoc.json for each
   - Merges into unified index

   File: .github/workflows/sync-and-deploy.yml
   - Added Rust toolchain setup
   - Integrated rustdoc generation step
   - Runs automatically on schedule/dispatch

HOW IT WORKS
================================================================================

BEFORE:
  Docs: See [[MyStruct]] for details
  Result: Broken link (no target)

AFTER (With RustDocBridge):
  Docs: See [[MyStruct]] for details
  Process:
    1. Load rustdoc.json (from cargo doc)
    2. Find MyStruct in index
    3. Resolve to: /api/my_crate/struct.MyStruct.html
  Result: Proper link to API docs

================================================================================
KEY TECHNICAL DECISIONS
================================================================================

1. Transformer Plugin
   - Operates on HTML after markdown conversion
   - Perfect for link rewriting
   - Efficient O(1) resolution

2. Smart Name Matching
   - Exact match first
   - Then case conversion
   - Then fully qualified matching

3. Index Caching
   - Built once per build
   - Reused across documents
   - Performance gain

4. Graceful Degradation
   - Missing JSON: works, no links resolve
   - Invalid JSON: works, logs warning
   - Unresolved links: stay as internal

5. Single Unified Index
   - All projects merged
   - Org-wide linking possible
   - Simple management

================================================================================
ARCHITECTURE OVERVIEW
================================================================================

Input: Markdown files with wikilinks

Processing Pipeline:
  1. ObsidianFlavoredMarkdown (convert [[name]])
  2. CrawlLinks (mark as "internal")
  3. RustDocBridge (resolve to rustdoc URLs)
  4. Generate HTML output

Data Flow:
  rustdoc.json -> Index (hash table) -> Link Resolution (O(1))

Output: HTML with proper API links
