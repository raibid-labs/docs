Troubleshooting

Elements Not Appearing in Hints

  1. Verify coordinates are correct (check with debug output)
  2. Ensure elements are registered every render
  3. Check that SCARAB_NAV_SOCKET is set
  4. Verify the host supports navigation mode

Performance Issues

  1. Avoid registering too many elements (> 100)
  2. Use debouncing for very high-frequency updates
  3. Only register visible elements
  4. Profile your render loop to identify bottlenecks

Mouse Events Not Working

  1. Ensure your TUI framework supports mouse events
  2. Enable mouse mode in your terminal
  3. Verify the host correctly synthesizes events
  4. Check element coordinates are accurate
