Technical Decisions Made

Decision 1: UI Deferral

Problem: Bevy 0.15 UI changes affect 40+ locations Solution: Temporarily stub UI, restore after core integration validated Impact: Faster time to working build, cleaner git history

Decision 2: Integration-First Approach

Problem: Too many components to wire simultaneously Solution: Create dedicated integration.rs module Impact: Clear separation of concerns, better testability

Decision 3: Component-Based Mesh Storage

Problem: Handle not a Component in Bevy 0.15 Solution: Store handle in TerminalMesh component Impact: Cleaner architecture, better ownership
