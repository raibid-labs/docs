Troubleshooting

High CPU Usage

  1. Check VTE parsing:
  1. Profile with flamegraph:
  1. Common fixes:
    • Batch VTE processing
    • Cache parsed sequences
    • Use lookup tables for state transitions

Memory Leaks

  1. Run Valgrind:
  1. Check for growing allocations:
  1. Common sources:
    • Unbounded channels
    • Cached data without eviction
    • Circular references in async code

Frame Drops

  1. Check render timing:

  1. Profile GPU usage:

    • Use RenderDoc or NSight
    • Check draw call count
    • Monitor GPU memory

  2. Optimizations:

    • Batch draw calls
    • Use instanced rendering
    • Implement frustum culling

Input Latency

  1. Measure end-to-end latency:

  1. Common causes:

    • Synchronous IPC
    • Lock contention
    • Event queue backlog

  2. Solutions:

    • Use async message passing
    • Reduce critical sections
    • Priority queue for input events
